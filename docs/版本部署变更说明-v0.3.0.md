## 1. 变更概览

### 1.1 新增

**画布（对齐 NoteGen 的 canvas）**

- 侧栏新增「画布」页签：列表、计数、新建（内联输入）、刷新、右键重命名 / 删除。
- 画布文档存 `canvases/*.canvas.json`（与 Markdown 树解耦，`fs/tree` 不会混入）：
  `{ "version": 1, "title": "", "nodes": [], "edges": [], "updatedAt": 0 }`。
- 编辑器交互：双击空白新建卡片、拖动移动、右侧圆点拖拽连线（贝塞尔曲线，点击连线删除）、
  空白处拖拽平移、滚轮以光标为锚点缩放（0.4–1.8）、`Delete` 删除选中、整理布局、适配视图。
- 600ms 防抖自动保存，切换 / 关闭画布前强制落盘；写入为「临时文件 + rename」原子操作。

**云同步（Git）**

- 设置 → 同步：状态卡（分支、git 版本、远端、改动数、最近提交）、远端地址保存、初始化仓库、
  提交改动、拉取（`--no-rebase --autostash`）、推送（`-u origin <branch>`）。
- 直接调用本机 `git`，认证交给系统凭据（credential helper / SSH key），插件不保存 token。
- 只使用可预期命令，不提供 `reset --hard` / `clean -fd`；无改动时提交返回 `{ committed: false }` 而非报错。

**助手能力：知识库 / 长期记忆 / 技能**

- 设置 → 助手：知识库开关、长期记忆（一句一条，Enter 提交）、技能库（改名 / 编辑提示词 / 删除 / 新增 / 恢复默认）。
- 对话输入区新增「知识库」与「工具」两个开关、技能下拉、已引用文件 chip。
- 知识库走**全文检索 + 截断注入**（不做向量化：沙箱没有 embedding 服务）：
  `fs/search` 取命中 → 正文命中优先 ≤3 篇 → 单篇 ≤1800 字、总预算 6000 字。
- 系统提示按「基础提示 + 技能约束 + 长期记忆 + 工具清单」拼装，全部来源可在设置里改。

**并排对照面板（分屏）**

- 编辑区右上 `PanelRight` 按钮或 `Ctrl/⌘ + \` 开合；默认挑一篇**不是当前笔记**的文件，避免左右互写。
- 面板内部独立读盘、独立 800ms 防抖写盘、下拉切换文件、保存状态展示，与主编辑区互不干扰。

**图片：粘贴入库 + 预览**

- 编辑器粘贴剪贴板图片 → `image/save` 落到 `assets/<uuid>.<ext>`，正文只留 `![](assets/xxx.png)`。
- 文件树显示图片节点，点击打开预览弹窗：Sidecar 通过 `image/read` 把文件读成 data URL 内联给 `<img>`。
- 宿主若连 `data:` 也禁掉，`<img>` 的 `onError` 会降级为「当前宿主禁止页面加载图片 + 说明 + 复制路径」。

**本地 MCP 工具**

- 设置 → 工具：添加服务（名称 / 启动命令 / 启动参数）、启用开关、删除、检测工具、展开工具后填 JSON 参数试运行。
- Sidecar 新增 `mcp` 模块：`initialize → tools/list / tools/call → 退出`，每次调用独立进程、用完即弃；
  Windows 经 `cmd /c` 拉起（`npx` / `uvx` 是 `.cmd`），并设置 `CREATE_NO_WINDOW` 不弹黑窗。
- 对话侧不依赖 function calling：把工具清单写进系统提示，模型以 ```` ```tool ```` 代码块申请调用，
  前端解析后执行并把结果回灌，最多两轮（防止死循环）。默认关闭，需在设置或对话里显式打开。

**移动端单栏**

- `(max-width: 860px)` 时切单栏：底部导航三个入口（文件 / 编辑 / AI 助手）+ `safe-area-inset-bottom`；
  标题栏隐藏品牌名、工作区名、搜索框与面板开关，只留搜索图标、外观、设置。

### 1.2 优化

- `APP_VERSION` 改为构建期从 `package.json` 注入，不再手工维护常量。
- `MarkdownEditor` 支持受控用法（`value` / `onChange`），对照面板据此共用同一套编辑器。
- 文件树拍平逻辑抽到 `src/lib/tree.ts`，对照面板与快捷键共用。
- 图片节点丢失「打开即报错」的旧路径：树里不再过滤图片，改为点开走预览。

### 1.3 修复

- `canvas/read` 越权：`resolve()` 限定在 `canvases/` 内（`starts_with(base)` + 后缀校验），越界返回 `-32602`。
- `sync/status` 中文路径显示为八进制转义：统一加 `-c core.quotepath=false` 并去掉首尾引号。
- Rust `fs::read_dir(...).filter_map` 误用（返回 `Result<ReadDir>`）、`serde_json::to_string_pretty` 无法直接转 `RpcError`：改为显式错误映射。
- 设置页「添加服务」先落盘再探测：新增服务初始没有 id，探测拿空 id 会报「找不到该 MCP 服务」。
- 设置页保存响应不再整体覆盖本地状态，只回填后端分配的 id，避免「失焦保存」的旧响应盖掉正在输入的命令 / 参数。

## 2. 接口变更

新增 15 个 Sidecar 方法，均为向后兼容的新增：

| 方法 | 入参 | 返回 |
| --- | --- | --- |
| `canvas/list` | — | `{ items: [{ path, title, updatedAt, nodeCount }] }` |
| `canvas/read` | `path` | `{ path, content }`（content 为 JSON 文本） |
| `canvas/create` | `name` | `{ path, title, content }`（同名自动加 `-2` 序号） |
| `canvas/save` | `path`、`content` | `{ ok, title, size }`（校验 JSON 合法性 + 原子写） |
| `canvas/rename` | `path`、`name` | `{ path, title }` |
| `canvas/delete` | `path` | `{ deleted }` |
| `sync/status` | — | `{ available, gitVersion, isRepo, branch, remote, ahead, behind, changed[], lastCommit, lastCommitMessage, lastCommitAt }` |
| `sync/init` | `url?` | 同 `sync/status` |
| `sync/remote` | `url` | 同 `sync/status` |
| `sync/commit` | `message?` | `{ committed, message, output }` |
| `sync/pull` | — | `{ output }` |
| `sync/push` | — | `{ output }` |
| `image/read` | `path` | `{ path, size, mime, dataUrl }`（>20MB 拒绝） |
| `mcp/list` | — | `{ servers: [{ id, name, command, args[], enabled }] }` |
| `mcp/save` | `servers[]` | `{ servers }`（缺 id 时后端补 uuid） |
| `mcp/tools` | `id` | `{ id, name, tools: [{ name, description, inputSchema }] }` |
| `mcp/call` | `id`、`tool`、`args` | `{ text, isError }` |

`image/save`（0.1.0 已有）在本版首次被前端使用：粘贴图片 → `{ path, markdown }`。

## 3. 配置与依赖变更

- 运行时配置新增 key `app.mcp`，示例：

```json
{
  "servers": [
    {
      "id": "0f0d1f6e-6f2f-4a9c-9b0b-1f1b2f5a7c11",
      "name": "本机文件",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "D:/notes"],
      "enabled": true
    }
  ]
}
```

- `app.settings` 快照新增 `mcpEnabled: boolean`（默认 `false`）；旧版本读到的快照缺该字段时按 `false` 处理。
- 前端依赖：无新增包（画布用 SVG + 原生事件，同步与 MCP 全部在 Sidecar 侧）。
- 后端依赖：无新增 crate（Git 走 `std::process`，MCP 走 stdio + `serde_json`）。
- 版本号：`manifest.json`、`package.json`、`backend/src/main.rs`（`PLUGIN_VERSION`）三处同步为 `0.3.0`。

## 4. 数据库变更

无 DDL 变更。仅新增运行时数据：

```sql
-- MCP 工具配置（由 Sidecar 通过 mcp/save 写入）
INSERT INTO settings (key, value, updated_at)
VALUES ('app.mcp', '{"servers":[]}', 1793617200000)
ON CONFLICT(key) DO UPDATE SET value = excluded.value, updated_at = excluded.updated_at;
```

`app.settings` 快照由前端整体写回，新增字段自动补齐；回滚到 0.2.0 时两个 key 均被忽略，无需清理。
工作区新增目录：`canvases/`（画布）、`assets/`（图片），均为普通文件，回滚后仍可用其他编辑器打开。

## 5. 部署流程

```bash
npm ci
npm run typecheck
npm run backend        # 固定 GNU 工具链，产出 backend/target/release/backend.exe
npm run build          # 产出 ui/（单文件 bundle）
npm run pack:local     # 产出 release/com.mjj3610.note-0.3.0-windows-x64.dbxp
```

> 改了后端后必须重启开发宿主（`npm run devhost -- --port 5196 --data .tmp/e2e-data`）：
> 宿主在启动时拉起 Sidecar 子进程，旧进程不会热更新。

安装 / 升级：

1. DBX 中关闭「笔记」工作台（旧版本先在插件管理里禁用）。
2. 备份 `DBX_PLUGIN_DATA_DIR`（生产：`D:\Program Files\DBX\data\plugin-data\com.mjj3610.note`）。
3. 插件管理 → 从本地安装 → 选择 `com.mjj3610.note-0.3.0-windows-x64.dbxp`。
4. 自检：侧栏出现「画布」页签；设置里出现「工具」「同步」两项；
   `Ctrl/⌘ + \` 能开合对照面板；粘贴一张图片后工作区出现 `assets/`。

回滚：禁用并卸载 0.3.0 → 安装 0.2.0 `.dbxp` → 恢复数据目录备份。
`canvases/`、`assets/` 对旧版本是普通文件（旧版文件树里 `canvases/` 会显示为文件夹、图片不显示），不影响编辑。

## 7. 已知问题与规避

1. **图片预览依赖宿主 CSP**：图片走 `data:` 内联，若宿主 `img-src` 为 `'none'` 则显示降级提示（复制路径用系统看图工具打开）。预览弹窗已按此设计，不会白屏。
2. **语音记录 / 截图未实现**：沙箱为 `allow-scripts` + 不透明源，`getUserMedia`、屏幕捕获均不可用；本机也没有可用的转写服务，故不做半成品入口。
3. **MCP 为进程级代理**：每个服务在工具探测 / 调用时启动一次，冷启动（`npx` 首次拉包）可能 10s 以上；已把超时放宽到 30s（握手 60s）。
4. **MCP 工具调用靠约定格式**：不走 OpenAI function calling（宿主侧只有纯文本流），模型若忽略格式约定则不会触发工具。
5. **云同步不做冲突合并**：`sync/pull` 用 `--no-rebase --autostash`，冲突会原样报错给用户，需自行在 Git 里解决。
6. **画布不做协同 / 撤销栈**：单文件 JSON 原子写，多端同时编辑以「后写覆盖」，靠 Git 提交留存版本。
7. **官方 CLI 打包需 MSVC**：`dbx-plugin package` 固定 msvc target；无 MSVC 时用 `npm run devhost` + `npm run pack:local`（同 0.2.0）。
