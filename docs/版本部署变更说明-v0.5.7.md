# 版本部署变更说明 v0.5.7

| 项 | 值 |
| --- | --- |
| 版本号 | 0.5.7 |
| 上一版 | 0.5.6 |
| 变更类型 | 缺陷修复 + 交互对齐 + 构建链路修复 |
| 数据兼容 | **无数据库 / 设置结构变更**，无需迁移；旧笔记中的数学公式在升级后重新打开即可正常解析 |
| 后端 RPC | 无新增 / 无删除，仅 `PLUGIN_VERSION` 与 crate 版本更新 |

## 1. 用户反馈与处理

| 反馈 | 根因 | 处理 |
| --- | --- | --- |
| 数学公式同步上传后丢失、重开后也没有 | `mathNodes.tsx` 两个节点漏配 `markdownTokenName`，`@tiptap/markdown` 解析时 token 被静默丢弃，防抖保存把丢公式的内容写回并覆盖云端 | 显式声明 `inline_math` / `block_math`；修 atom 节点非法 `content`；规范块级公式序列化 |
| 行内输入 `/` 带不出块编辑菜单 | `SlashMenu.tsx` 用 `^\/(...)$` 行首正则，正文之后不触发 | 改为参考项目 `findSlashMatch` 语义：块首 / 空白 / 标点后触发，排除链接目标，只删 `/query` |
| 块前 `+` 移动过去就消失 | 手柄在 `containerRef` 外（`left:-46`），穿过装订线触发 `mouseleave` 且零延迟清空 + `pointerEvents:none` | 280ms 延迟隐藏 + 透明过桥带 + hover 状态锁 |
| 关一个 tab 其它 tab 先消失 | `closeTabs()` 先 `blankEditor()` 置空 `activePath`，`EditorPane` 卸载 `<EditorTabBar>`，异步读盘期间出现空窗 | `takeOverTab()` 同一次 state 更新接管邻居；标签栏常驻 + Spinner 过渡态 |
| （附带）CI 偶发 504 | `package-lock.json` 里 121 条 npmmirror 绝对 URL | 全部替换为 `registry.npmjs.org`，锁文件版本同步 0.5.7 |

## 5. 部署步骤

与 0.5.6 一致：

```bash
npm ci                 # 本版起不再访问 npmmirror
npm run typecheck
npm run build
npm run backend        # release Sidecar
npm run sidecar-check
npm run smoke
npm run e2e
```

发布时按 `dbx-store-publish` 流程：

1. 只读核对上游 `t8y2/dbx-store` 本插件 open candidate；**0.5.6 的 PR #493 当前仍 open**，
   若发布 0.5.7 需先关闭或取代，保证同一插件只有一个待签名候选；
2. 推送源码 → 创建 `v0.5.7` tag 与 Release；
3. 等 5 平台 CI（windows-x64 / linux-x64 / linux-arm64 / darwin-x64 / darwin-arm64）；
4. 从 Release 资产下载 `release-candidates.json`，生成并校验候选 JSON；
5. 提商店候选 PR，`Validate catalog` 报 `awaiting DBX Store signing` 为预期失败；
6. 等维护者 `/sign`。

## 7. 升级注意

- **数学公式**：升级前若已有笔记因旧版 bug 被写回覆盖，云端原始公式可能已经丢失，
  本版只能保证升级后不再继续破坏；这类历史内容需从 Git 远端提交历史（编辑器底栏
  「历史版本」）恢复。
- **无需数据迁移**：没有新增表、没有新增设置分组，`app.settings` 结构不变。
- **前端产物必须重新构建**：`ui/` 由 `npm run build` 生成；本机 `vite` 的
  `emptyOutDir` 在 WorkBuddy 删除保护下可能超时，可先把旧 `ui` 移到 `.tmp/` 再建空目录重建
  （本版实际采用此方法，构建成功）。
- **Sidecar 必须重新构建**：`PLUGIN_VERSION` 变了，宿主握手版本需与 `manifest.json` 一致。
