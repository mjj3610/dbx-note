# v0.5.2 — 进入即见云端更新 · 截图选区可缩放

## 修复

- **进入应用就能看到远端更新**：新增「远端目录清单」拉取，进入文件树 / 回到前台时自动合并
  云端节点。另一台设备新增的笔记现在会直接出现在侧栏（云下载图标），点开才下载正文 ——
  与参考项目 `loadRemoteSyncFiles()` 完全一致，且不会在冷启动时把全部笔记正文拉下来。
- **打开时自动拉取不再被「自动同步间隔」误关**：间隔设为「关闭」只关闭自动推送，
  打开笔记、切回应用时的远端比对照常进行。
- **已有笔记的远端更新**：文件树标记「云端有更新」，当前打开的笔记会自动刷新到新版本；
  两边都改过仍走冲突弹窗。
- **全局截图选区可以拖着改大小了**：框选完、还没复制 / 保存之前，8 个定位点悬停会显示
  系统双箭头光标，拖拽即可调整选区；标注内容、工具栏与最终输出尺寸都会跟着走。
- **后台同步不再拖慢界面**：远端清单刷新加了去重与节流，当前笔记的更新复用同一份清单，
  不再每次聚焦都额外跑一次 `git fetch`。
- **连续改设置不会互相覆盖**：设置保存改成串行队列，慢后端下也不会出现「刚切到 PicGo，
  磁盘上的配置又变回本地存储」这类旧值覆盖新值的问题。
- **切换图床更可靠**：填好地址点「测试连接」后，不会再被切换页签时那次自动检测的
  失败结果覆盖回「未连接」；「使用此服务」不会莫名其妙变灰，且始终读取最新填写的配置。
- **文件树不再被外层 Git 仓库污染**：工作区目录没有独立 `.git` 时，不会再误把插件源码
  仓库的文件列成云端笔记。

## 新增

- 云端节点右键「下载到本地」/「下载目录内全部云端文件」；云端节点不再提供重命名与删除。
- 文件树状态标记：`remoteOnly`（云端文件）、`remoteUpdated`（云端有更新）。
- 对象存储 / WebDAV / 自托管通道同样支持进入时列远端清单。
- 回归覆盖：3 项 Rust 单元测试（8 方向缩放、最小尺寸 / 不翻转 / 不越屏、手柄点位），
  以及 Sidecar 自检里 5 项远端清单语义断言。

## 说明

- 冷启动只拉清单、不自动下载全部正文；需要全量下载请用设置 → 云同步 →「拉取全部远程文件」。
- 同步基线、冲突处理、推送重试等 0.5.1 的行为不变；无数据库变更，覆盖安装即可。
- 截图缩放只在全局热键路径（原地标注、还没选出口）可用；编辑器内相机按钮仍把图交回插件浮层。
