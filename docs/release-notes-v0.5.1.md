# v0.5.1 — 打开笔记即拉取远端更新

## 修复

- **打开笔记时按需拉取远端版本**：Git 通道改成与参考项目一致的逐文件比对 ——
  先用 `git fetch` 取远端树，再按「基线 / 本地 / 远端」三路比较，只拉真正变化的那个文件。
- **拉完刷新界面**：文件树与当前正文会立即重新加载，不再需要手动关开。
- **不再覆盖你的修改**：本地有未推送改动、远端也改过同一篇时，弹窗让你选保留哪边，
  而不是静默用远端覆盖。
- **推送更稳**：远端已被别的设备推进时自动合并一次再推，不会静默失败后本地开始分叉。

## 新增

- 设置 → 云同步 增加「**拉取全部远程文件**」，新设备首次使用可以从这里拉全量。
- 冲突弹窗：左右并排显示本地与远端内容，可选「保留本地 / 采用远端」。

## 说明

- 对象存储 / WebDAV / 自托管通道逻辑未变（本来就是逐文件 + 基线哈希）。
- 同步基线保存在 `.git/dbx-note-sync-state.json`，不会进入笔记内容。
- 无数据库变更，覆盖安装即可。
